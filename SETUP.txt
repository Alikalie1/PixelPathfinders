PIXEL PATHFINDERS WEBSITE
========================

The site stays in this folder. index.html is the homepage; the remaining HTML
files are independent pages connected through the shared navigation.

Database and admin setup
------------------------
1. Make sure the Auth user with the supplied UID and email exists in Supabase.
2. Run supabase/website-cms-admin.sql in the Supabase SQL Editor. It creates
   the website content, admin-role, website-data and form-submission schema,
   enables row-level security, promotes that existing account to super admin,
   enables member profiles and private, account-owned registration history, and
   adds social icon visibility settings and the homepage hero image setting.
   Rerun after making CMS schema updates.
   If an earlier run stopped with an error, rerun the updated file. Do not run
   this file from browser code.
3. Authenticate the Supabase CLI with `supabase login`, then deploy the admin
   invitation function with
   `supabase functions deploy invite-admin --project-ref naejurohofikbcwgawmj`.
   The function uses Supabase server secrets; never put a service_role key in
   config.js or any other browser file.
4. Sign in at /admin/ with the promoted account. Super admins can invite or
   remove admins there. The dashboard sidebar groups page publishing, page
   text, content cards, navigation, site settings, website records and the
   private form inbox. Admins can upload card, team and gallery images into the
   Supabase media bucket. Website text, links, settings, records and uploaded
   image URLs are saved in Supabase; the dashboard offers a public-page preview.
   Add partner logos from Content cards by choosing Home: partner logos, adding
   the partner name, and uploading its image. Toggle individual footer social
   icons from Site settings.
   Members can create an account and sign in on the Join page. After
   authentication they are redirected to member-dashboard.html, a private
   dashboard without the public site header or footer. New account profile
   details are saved to profiles by the Auth signup trigger; members can update
   those details, view published upcoming sessions, register for a session,
   apply as a volunteer, and review their own activity there. The site settings
   include the home hero stock photo URL; admins can replace it with a URL or
   upload an image to Supabase Storage. Public and admin pages include an
   accessibility menu for larger text, high contrast, and reduced motion.
   Page text selection, copying and dragging are restricted; form controls
   remain selectable. This browser-side restriction is a deterrent, not
   protection against screenshots or access to page source.
5. Registration, volunteer, partner and contact submissions are private.
   Row-level security lets visitors submit forms but only admins read them.

The Supabase URL and publishable/anon key are configured in config.js.

Before launch, replace the example email and placeholder social links in the
page footers with the organisation's real contact details.
